## 1. Why the OFF eigenfrequency was 0.12 GHz low in the MoM, and the recalibration (`sidequest_offcal.py`, `k2_offcal.json`)
r 2.20 cell at 90 deg, eigenfrequency [GHz] (HFSS: OFF 10.0193, ON 10.3617):
| mesh | 64 | 80 | 96 | HFSS |
|---|---|---|---|---|
| OFF (open slit) | 9.899 | 9.969 | 9.902 | 10.019 |
| ON (2.44 ohm) | 10.356 | 10.380 | 10.345 | 10.362 |
Cell susceptance HFSS requires at the OFF frequency vs the MoM: OFF 6.92 mS against 7.77 / 7.26 / 7.74 mS (mesh 64 / 80 / 96); ON is within 0.03-0.10 mS. Contrast OFF - ON at 10.02 GHz: HFSS-implied 1.81 mS against MoM 2.63 / 2.23 / 2.53 mS, ratio **0.69 / 0.81 / 0.71**; the eigenfrequency-shift ratio is 0.75 / 0.83 / 0.77. So the HFSS contrast is **x0.75 (range 0.69-0.81 over the meshes)** of the MoM contrast, ON fixed.
Cause: not the diode sheet (OFF has none in HFSS and none in the MoM), not eps_r or the geometry (ON matches to 0.006 GHz); it is the open-slit model: the OFF susceptance is over-estimated by 0.3-0.85 mS (4-11 %) and the error is not monotonic in the mesh (OFF 9.899 / 9.969 / 9.902 GHz), i.e. a pixel / staircase limit of the narrow rim (0.2 mm = 2-3 pixels) and slit (0.4 mm = 4-6 pixels) plus the zero metal thickness of the MoM (HFSS has 35 um). It is not converged and not resolved to one cause; it is calibrated, not fixed.
Recalibration applied to the final cell library (MoM mesh 96, r 2.22): Y_cal = Y_ON + 0.75 (Y - Y_ON) (affine, ON fixed; normalised static levels unchanged, Ybar and dY change). The RT5880 ratio 3.13/2.63 is no longer used. **r 2.22: Ybar 6.96 -> 6.59 mS, dY 2.92 (MoM) -> 2.19 mS, direct A0 = 1.53 Np/m (x1.8 the baseline 0.844), beta/k0 1.186** (without the calibration A0 would be about 3). A0 at r 2.26: 4.27 (beta/k0 1.244); r 2.30: 11.3 (1.346) [mesh 96, same calibration].

## 2. State-2 split lobe and the isolation gap (model analysis; the HFSS patterns are not in the sandbox: `rE_state*.csv` needed to confirm)
Model of the baseline board (`sidequest_split_lobe.py`, `k2_split_lobe.json`, `k2_split_lobe_sens.json`):
* The static cells (same m in both states) radiate toward (25, 180) in BOTH states at -4.9 / -5.2 dB below the main beam; the switched cells add -6.7 / -7.0 dB: the wrong-beam suppression is an INTERFERENCE of two -5 dB contributions (model other-beam level -19 dB at the grid point). It is fragile: +-10 % in the static levels or the OFF level moves the other-beam level by 3-6 dB (static +15 % -> -15 dB; OFF -15 % -> -14 dB; ON -15 % -> -15 dB in state 2). HFSS state 2 (14.6 dB against the model 15.1) is on target; state 1 (10 dB against 15) is the pattern of a 10-15 % OFF/static level error, i.e. the same OFF-model problem found in the cell check.
* The lobe (20, 154) at -0.1 dB is not a main-beam shoulder in the model (shoulder -5.6 dB at that point), not a beta error (state-2 beta shifts -0.04 .. +0.08 k0 leave the peak at (25, 180) and the shoulder at -4.4 .. -5.6 dB), and not a static-only lobe (static-only -9.5 dB there). The strongest model sidelobe is -11.7 / -11.8 dB at (30, 48) / (29, 132). The HFSS strongest sidelobes are 8.3 dBi (state 1, -0.8 dB) and 8.2 dBi (state 2, -0.1 dB): the SAME ABSOLUTE LEVEL in both states, which points to a state-independent source (probe direct radiation plus edge diffraction, 70-80 % of the power per the HFSS split), not to a state-2 hologram error; the (20, 154) direction (9 deg from the beam) says the broad low-efficiency pedestal merges with the beam. Open question: its direction in state 1 (send `rE_state1.csv`).
* Calibration with both states (rebuilt baseline pipeline 10.88 / 11.0 dBi against HFSS 9.1 / 8.3): gain offsets -1.78 dB (state 1) and -2.7 dB (state 2); non-beam floor absolute level 10 log(NB x 7.45) dBi, NB = (1 - launch) + launch x SW-at-edge (baseline NB 0.90 -> 8.3 dBi). The old isolation floor (0.63 NB) is dropped: it fitted state 1 but over-predicted state 2 (-1.2 dBi against HFSS -6.6 dBi), so the 10 dB of state 1 is a cancellation failure, not a floor.

## 4. Result: **SLL <= -13 dB is NOT reachable at r 2.22 without a rim (or more leakage). Best achievable total SLL: -4.8 dB (state 1) / -4.2 dB (state 2)** at isolation 13 dB; -6.9 / -5.9 dB only by giving up isolation (8.6 dB).
The limit is the state-independent non-beam power, not the hologram: NB = 0.29 (direct probe) + 0.71 x 70 % (SW reaching the edge) = 0.79 of the input, absolute level 7.7 dBi against a beam of 12 dBi. The aperture SLL alone is -11.9 / -11.9 dB. With the pad (launch 0.96) the direct share falls to 4 % but the edge share stays 70 %, so the floor improves by only about 0.5 dB and the gain by 1.3 dB.
Without changing r the only levers are the extra parts (absorbing rim) or more leakage. For information (not built, same calibration, mesh 96): r 2.26 (A0 4.27, beta/k0 1.244): gain 15.5 / 14.9 dBi, SLL total -8.8 / -8.2 dB, isolation 15.1 / 14.1, SW at the edge 47 %; **r 2.30 (A0 11.3, beta/k0 1.346): 16.8 / 14.7 dBi, SLL total -11.4 / -10.2 dB (aperture -11.4, floor -12.3 / -10.2), isolation 14.2 / 13.7, SW at the edge 12 %** (state imbalance 2 dB; tolerance, pointing and the bound-mode flag of K2_POINTING.md apply, beta/k0 > 1.3). Even r 2.30 stays 1.6-2.8 dB short of -13 dB. Decision for the user: r 2.22 is delivered as instructed; r 2.26 / 2.30 libraries (`ro3006_r2.26_mesh96_lib.json`, `ro3006_r2.3_mesh96_lib.json`) are ready for a second package.
