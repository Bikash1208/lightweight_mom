## 1. Architecture history and why
1. **Gates (A, quadrant gate rows)** - ideal study (`ARCH_STUDY.md`) then dog-bone gate cell + ring model. In-plane diode gates gave only ~2-3 dB isolation once a damped quasi-TEM root was handled correctly (an earlier "16 dB" was a root-finder artefact, disclosed); block state cost 3 dB. Dog-bone test board archived, never run.
2. **Mushroom via-diode gate** - model recalibrated after the first HFSS baseline (ON failed, resonance 2.2x low); variants never returned; parked (and possibly affected by the setup errors in sec. 2).
3. **Switched pin launcher** - network model (12 pins, F/B 10.6 dB, S11 -10.3 dB, 4 quadrants not met), two-probe fallback; parked in favour of the hologram (`LAUNCHER_STUDY.md`).
4. **Grouped coded 1-bit hologram (current)** - whole aperture coded; cells identical in all K states are static (no diode); switched cells grouped by state word to few control lines. Chosen because gain, diode count and lines are all controllable in one model (`CODED_HOLOGRAM.md` ... `CODED_K4.md`, `DIODE_REDUCTION.md`). Route choices: crossed two-diode rim-disc cell on RT5880 over a rotated one-diode disc (higher alpha, AR/XPD) and over RO3010 (ap. eff. 1.15x, not 2x; strong-scatterer superpixel outside first-order validity).
Model corrections to remember: cell tensors must be taken at kt = beta (loaded Bloch tensor), not at normal incidence (alpha 0.7 -> 1.3-1.9 Np/m); ohmic loss only for ON diodes.

## 2. Current cell status (HFSS, user-run)
Cell = RT5880 disc r 3.0 mm, slits 0.4 x 5.6 (rim 0.2 mm at 4 ends), x diode across the vertical slit at y = +0.8, y diode at x = +0.8, footprint 0.4 x 1.0. **After fixing the HFSS setup** (air box ground-bottom-to-lid, single-face lattice pairs, `pec` on the metal), x run at 90 deg: **C/C 10.670, R/C 10.665, C/R 10.690, R/R 11.006 GHz** (DX/DY; R = 2.44 ohm = ON, C = 28.16 fF = OFF). Model: 10.525 / 10.990 / 10.528 / 11.014.
* **Both diodes together switch (+0.336 GHz); each alone does not.** The MoM predicted independent switching - falsified. MoM agrees at the extremes (open-slit 10.662 vs C/C; R/R 11.014; implied Y 10.07 -> 6.94 mS, dY -3.13 mS, alpha_beam 0.844 Np/m for the scalar switch) but not at R/C, C/R, and the 28 fF OFF capacitor has no effect in HFSS.
* MoM checks (`CELL_INDEPENDENCE.md`): the MoM bridges only the 1.0 mm footprint, and a half-bridged slit already gives ~75 % of the full effect (strap 0.5 mm -3.66, whole half -3.93, both halves -5.0 mS: current crowding, L ~ 4 nH); not a mesh artefact (-4.14/-3.77/-3.57 mS at mesh 32/64/96); missing top/right rims reproduce neither HFSS number. **Cause unresolved, probably HFSS-side** (mode tracking, RLC boundary behaviour for single states).
* **Boundary audit** (`EIGENMODE_BOUNDARY_AUDIT.md`): errors found = metal imported as vacuum (STEP has no material) and periodic pairs on single faces leaving substrate walls PEC. Invalid: first RT5880 run (11.059/11.055) and the "bare substrate 11.07 GHz" (model 11.42). Possibly affected: mushroom baseline (its recalibration is unconfirmed). Unlikely: Phase 30 E1 eigenmodes (sheet selects both faces; 0.5 % agreement). Not affected by the pair error: Floquet-driven and full-board runs.

## 8. Rotated-load fix (commit `fcc6691`) - review before any merge to main
Bug (Phase 28): diode loads on a non-axis direction froze the footprint to an open circuit in every state (ON = OFF): `diodes_measured.load` / `diodes.diode_load` hard-coded `transverse_conducts=False`, and the pointwise block v.J = 0 is unrepresentable on x/y rooftops for a few-cell footprint. Fix (additive): `loads.default_transverse_conducts(direction)` (False for x/y/0/90, True otherwise; `transverse_conducts=None` default; explicit value honoured; warning for rotated blocked loads); axis-aligned `load_matrix` bit-identical; no solver kernel touched. Tests `tests/test_loads_rotated_diode.py` (ON != OFF, rotation covariance, reciprocity, mirror, 0/90 agreement). Touches `src/loads.py`, `src/ris/diodes.py`, `src/ris/diodes_measured.py`, `docs/STATUS.md` row; CLAUDE.md "documented exceptions" is not updated.
