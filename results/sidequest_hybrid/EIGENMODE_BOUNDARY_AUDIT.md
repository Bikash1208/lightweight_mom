# Which HFSS eigenmode results may have been affected by the setup errors? (2026-11-05)
Errors found on the RT5880 cell: (a) the STEP imported the metal as vacuum (no material in STEP); (b) periodic (lattice) pairs on single faces of the air above the substrate left the substrate side walls PEC (unassigned faces default to PEC), which gives a bare-substrate answer. Evidence: OFF 11.059 / ON 11.055 GHz (and the user-measured bare value 11.07 GHz) before the fix; OFF/OFF 10.670, DX ON 11.006 GHz after (air box from ground bottom to lid, `pec` assigned).
| HFSS result in the repository | setup as documented | status |
|---|---|---|
| RT5880 coded cell, first run (OFF 11.059 / ON 11.055 GHz at 90 deg) | single-face pairs, metal as vacuum | **affected, invalid**; replaced by the 2026-11-05 run |
| bare-substrate value 11.07 GHz | PEC substrate walls | **affected**: the bare model value (11.42 GHz) was never contradicted; re-measure with the air box |
| Mushroom via-diode gate cell baseline (`hfss_results/sidequest_mushroom_baseline/NOTES.md`: OFF 3.86 / 7.66 / 10.98 ... GHz, ON flat band 4.9-5.1 GHz, second band almost identical to OFF) | sheet says "master/slave on the x faces / y faces", not "both faces", no `pec` step; the notes do not describe the user's setup | **possibly affected**. OFF agrees with the model to 2 % up to 90 deg, so the periodic setup probably worked for OFF; the ON "nearly identical to OFF" pattern is the symptom of an inactive diode boundary or missing conductor. The round-5 recalibration (M1/M2: L_br 6.0 nH, kappa 4.77) rests on this ON run and is **unconfirmed**; the mushroom route is parked |
| Phase 30 E1 eigenmode (4 cells; E1 eps_r 10.2 / 11.2, `results/phase30/HFSS_EIGEN_E1.md`) | sheet instructs selecting BOTH the SUB-side and AIR-side faces of every pair; no `pec` step | **unlikely affected**: model agreement 0.5 % in f, eps_r response agrees; confirm which setup was used |
| Phase 30 S1 supercell (Q 403 vs model 45-91) | same sheet, top Radiation boundary | **unlikely affected by the walls**; the Q discrepancy has other candidates (`LIBRARY_REPORT.md`) |
| Phase 20 R3 CP-2 cell (Floquet-driven, MADP diodes) | Floquet ports, not eigenmode | not affected by the lattice-pair error; the vacuum-import risk applies to any STEP-based run (no evidence either way) |
| Full-board HFSS (hex150 etc.) | no periodic pairs | not affected by the pair error; vacuum-import risk as above |
Model-side consequences: the 2026-11-05 run changes only the OFF-state loading (HFSS OFF capacitance effectively ~0, `CELL_VALIDATION.md`); no other model was refuted by an affected run except the mushroom ON result, which stays unconfirmed.
