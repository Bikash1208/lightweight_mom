# Validation index

Every place this project's own model has been checked against something external (HFSS) or
independently cross-checked (a second measurement technique inside this project, not just "it
runs"), with the actual numbers and where the data lives. See `docs/STATUS.md` for the current
summary table; this page is the detail and the provenance behind it.

## 1. Phase 12 HFSS unit-cell comparisons

Single-cell, grounded 8 mm design point, cases G1–G6 (`hfss_exports/phase12_grounded_8mm/`),
ingested via `src/phase9/hfss_reference.py:read_touchstone` and compared via
`src/hfss_compare/`. Full account: `docs/history/PHASE13_WEBAPP.md` Part 0.

| Case | Condition | Result |
|---|---|---|
| G1 (L = 2.0 mm, off-resonance) | HFSS 2025 R1 vs this project's MoM | mean phase diff **-0.2935°**, max \|S11\| diff **~1.6e-5**. `HFSS_VALIDATED_OFF_RESONANCE`. |
| G4 (L = 6.0 mm, at resonance, 12.5 GHz) | HFSS vs the 0.2 mm production mesh | total diff **13.51°** = mesh-convergence **5.93°** (Richardson extrapolation, `src/phase13/convergence.py`, fitted order p=0.96) + thickness **3.66°** (G6, 35 µm real patch, vs G4 zero-thickness) + **residual 3.92° unexplained**. |
| G4 at 11.5 / 13.5 GHz | same decomposition | mesh 5.12°/3.76° thickness/3.44° residual; mesh 4.59°/2.14° thickness/3.02° residual. |
| G2, G3, G5 | — | no real HFSS run yet. |

Reproduced independently through the live app's own HFSS-compare endpoint (not just the offline
script): G1 mean phase diff matched to full floating-point precision
(`docs/history/PHASE13_WEBAPP.md` "Verified against the app").

## 2. Independent cross-check: vortex/pencil physics (Phase 15 Part B)

A monopole-fed board's surface current is radial; decomposed into circular polarization that
carries an orbital-angular-momentum (OAM) term the project's own earlier *scalar* pattern model
could not see. Checked with a genuine *vector* far-field model
(`src/pattern/vector_aperture_pattern.py`, via this project's own layered Green's function — not
HFSS, an independent measurement technique inside the same codebase). Full account:
`docs/history/PHASE15_POLARIZATION_VORTEX.md`.

- **Natural polarization radiates a vortex, as HFSS originally showed**: measured null **-53 dB**
  with `|winding| = 1`, matching the HFSS observation that started Phase 15.
- **Per-beam polarization compensation (Part A) gives a genuine pencil beam**: XPD >= 15 dB
  target; measured **RHCP/LHCP 21.4 dB**, **HP 341 dB**, **VP 62 dB** (HP/VP exceed CP because the
  scalar, isotropic unit cell can fully null one linear component but not both circular ones —
  see "Scalar, isotropic unit cells cap achievable XPD" in the same doc).
- **A deliberately requested extra OAM charge gives a deep null with matching winding**: RHCP
  `oam_charge=-1` -> winding -1, null -31 dB; `oam_charge=-2` -> winding -2, null -32 dB.
- Walk-through board, real browser run: beam 1 (RHCP, Pencil) measured 19.8 dB XPD, ~0 dB null,
  ~0 winding; beam 2 (Horizontal, deliberate Vortex charge 1) measured a genuine -30 dB null with
  winding ≈ +1.0 (`docs/USER_GUIDE.md` Step 3, screenshot `phase15_step3_per_beam_results.png`).

## 3. Independent cross-check: multi-port pointing (Phase 16 follow-ups)

`src/hologram/pointing_correction.py`, measured on a fine 0.1°-resolution local evaluation of the
vector far field (not the shared, coarser plotting grid — see `tests/
test_hologram_multi_port_beam_pointing.py`):

- 1×3 RHCP board, 25° steering: achieved within 1.0–1.5° uncorrected.
- A beam that stalled at a 1.4° miss under the old (coarser) measurement now converges to **<0.3°**
  within 2 correction passes.
- 4-beam single port, equal requested levels: raw level spread **6.4 dB** -> **0.5 dB** after 2
  level-matching passes (`tests/test_hologram_formulation_a_saturation.py`).

## 4. Mishra et al. (IEEE TVT 2026) 26 GHz 5-port reproduction

Full comparison table (cell pair, board size, per-port pointing/levels, port-5 equalisation):
`docs/submission/paper26/comparison.md`, generated by `examples/make_paper_board_26ghz.py`.
Reproduces the paper's *target beam directions* with this project's own synthesis — not an HFSS
validation of the paper's measured hardware (isolation >30 dB, gain 13.8–16.7 dBic are the paper's
own measured numbers, not reproduced here):

- Cell pair (2.57 mm period, 25–27 GHz): phase separation 173–179°, essentially lossless
  (\|S11\| within 0.01 dB of 0).
- Per-port pointing error: 0–11.1° across the two surface-wave-beta modes tested ("paper mode" vs
  this model's own mixed-sheet-admittance mode).
- Port 5 (4-beam receive port) level equalisation: beam levels matched to <=0.1 dB after
  iteration (same `balance_beam_levels` machinery as item 3 above).

## 5. Square-loop FSS reference (self-consistency, HFSS pending)

`hfss_exports/fss_square_loop_10mm/`: a square-loop FSS unit cell (10 mm period, Rogers RT/duroid
5880, 1.0 mm) measured TWO ways inside this project — the standard infinite-periodic Floquet MoM,
and a finite 11×11-panel measurement-plane technique (`scripts/adhoc/fss/plane_s.py`,
parked as `docs/briefs/_parked/PHASE16_UNIT_CELL_SPARAM_TOOL.md`) that projects the field onto a
plane in front of/behind a finite panel and moves the phase back to the substrate faces. This is a
**self-consistency check between two measurement techniques in this project, not an HFSS
comparison** — no HFSS data exists for this geometry yet (`hfss_exports/README.md`).
