# STEP export noise: audit, cause, fix (stage: sub6-step-fix)

**Audit of the STEP text (50 files in `hfss_exports/`).** 3-D coordinates (CARTESIAN_POINT with 3 values), radii and DIRECTION values carry NO noise in any file: every literal that is a design value is exactly the double of its 3-decimal literal; irrational values (circle/line intersections such as 5.411952050785) are legitimate. `3.9999999999`-type literals were not found in any file of the repo.
What the audit did find:
* **16 literals per notch file** (`CELL{1,2}_notch.step`): 2-D parameter-space B-spline control points of the face pcurves, `-0.0350006`, `6.E-7`, `-0.0450006`, `-0.0099994` (6e-7 mm off the design values -0.035, 0, -0.045, -0.01). Cause: (a) the kernel approximates the pcurves with about 6e-7 error, larger than `SNAP_TOL_MM = 1e-7` of `src/transmitarray/export.snap_step_text` (the snap layer used by the package), and (b) the mirrored values (-T, -T/2) were missing from the package's `intended()` table.
* **COLOUR_RGB reals** with float32 noise (`0.250000000672`, `9.999999991362E-02`) in every file with a coloured assembly.
Not a unit-conversion issue: `src/cad_export.py` is not used by the sub6 packages and was not changed; no opt-in parameter was needed (item 3 of the request does not apply).
If your HFSS shows `3.9999999999` on object dimensions, the value is not in these STEP files: please send one example (object, parameter, value, HFSS version) so the import path can be examined.

**Fix (package layer, `scripts/research/sub6_step_exact.py`).** `exactify_step_text` replaces every numeric literal of the DATA section (outside quotes, except UNCERTAINTY and COLOUR_RGB) within 2e-6 mm of a multiple of 0.001 mm by exactly that value, rounds colours to 4 decimals; `audit_step_text` is the regression predicate (empty list = exact). `sub6_slotdisc_hfss_package.py geometry` now applies it after the existing snap and fails EXACT_DIMS if the audit is non-empty. Test: `tests/test_sub6_step_exact.py` (4.000 mm box and 1.00 x 0.35 mm sheet exact to 1e-9 mm, noisy synthetic text, CELL1 notch cell).

**Re-export of `hfss_exports/sub6_slotdisc_cell/*.step`** (same geometry): non-colour literals 1257 / 1550 per file unchanged except in the notch files, 16 pcurve points moved by 6e-7 mm to the design values (`-0.0350006 -> -0.035`, `6.E-7 -> 0`, `-0.0450006 -> -0.045`, `-0.0099994 -> -0.01`); colours rounded (`0.250000000672 -> 0.25`); all geometry checks (re-imported STEP) pass. **The `.step` files are git-ignored (`hfss_exports/**/*.step`) and are not in the commit**: regenerate with `python scripts/research/sub6_slotdisc_hfss_package.py geometry`.
