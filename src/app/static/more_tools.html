More tools

The 3-step designer on the Home page covers the main HMSA workflow end to end. These pages are the lower-level building blocks it uses internally: useful for a reflectarray (not HMSA) design, for inspecting a single unit cell or library directly, or for checking a design against a full-wave solve or measured HFSS data.

Unit cell

Check one cell's reflection, plus diagnostics and STEP export.

Unit-cell library

Build or browse a phase-vs-size sweep for a board/substrate.

Reflectarray designer

Feed-illuminated reflectarray design from a library (not a hologram).

Pattern prediction

Far field from any design job's aperture, standalone.

Export

STEP/layout/README export from any design job, standalone.

Full-wave check (Verify)

A real supercell MoM solve vs. the lookup-table prediction.

HFSS comparison

Compare an HFSS export against this project's own solver.

Diagnostics & logs

Every job's request/run details are written to ~/.lwmom/logs/lwmom.log (JSON lines, filterable by the job ID shown in its status line/URL). There's no dedicated page for browsing them yet: see docs/DEVELOPING.md "Reading a diagnostic bundle".
