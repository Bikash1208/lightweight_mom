# sub6-board-edge (MODEL_ONLY; branch compute/sub6-board-edge from compute/sub6-board-island)
Same V3 method as sub6-board-island followup. SWITCHED cells = edge-diode 90 deg rows from results/sub6_edge_diode (OFF radiates, ON quiet; real OFF/ON tensors and beta). Architecture as island: static cells (NOCUT rows) carry beam A, switched cells carry beam B (OFF = A+B, ON = A). CONSTRAINT: switched cells lie in straight lines along the diode axis (consecutive neighbours, each line a series string), line length 10-24 cells; optimise line positions/orientation (lines may run along x or y; cell slots rotated per the hologram but the diode axis follows the line). Sweep N 135 and 240, sides 200/220 mm. Report gates, gains, eta, beta-shift effect on beam A, number of lines and string voltages (0.95 V/diode at 10 mA). Commit, push github, RESULT format, STOP.

Amendment: add variant EDGE_TO_EDGE: every switched line must span the board from edge to edge (a full chord of the hexagon along x or y, all cells on it switched), so both string ends sit at the rim (bias via edge traces, no vias, 2-layer board). Choose which chords (and direction) to use; report N, number of lines, longest string voltage (0.95 V/diode at 10 mA), and the gates. Compare with the free-segment variant. If a full chord is too long for one string, report the needed string voltage anyway.
Standing rules + area note: use only 90 deg rows for now; where cells along a line would need angles other than 0/45/90 deg, report NEED_ANGLE_TABLE instead of guessing. Push github, RESULT, STOP.
