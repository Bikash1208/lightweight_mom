# R5-3 report: beam table, bandwidth and sensitivity (MODEL_ONLY)

Generated by `scripts/research/phase20_r5_beam_table.py` from `beam_table.json` (provenance inside). Normal incidence, 20 x 20 cells, 15 mm pitch, 10.5 GHz, CP-2 library + run-2 HFSS delta (`HFSS_CALIBRATED` at theta<=30 / phi=0 cell responses, MODEL_ONLY pattern), assumptions `LOCAL_RESPONSE_AT_INCIDENT_ANGLE_ASSUMED`, `NOT_HFSS_VALIDATED`. Gain = 4 pi U / P_inc (intercepted power), obliquity cos(theta).

**phi_s = 0 and phi_s = 90 give identical numbers for plain/tilt: True.** At normal incidence the cell response is phi-independent in this model and the 20 x 20 array is square, so the two planes differ only through the dither / refinement seeds. This is a property of the model, NOT a verification of the physical cell (diode and stub placement are not 4-fold symmetric); a phi_s = 90 check needs the array-level run or HFSS.
