## 3. Cell sign convention in the code (report only)
- **NOCUT static disc:** the model has no "high-reactance axis" input. `src/hologram/tensor_leaky_cp.py` docstring (lines 12-14) and `cell_design` (159-162): the cell is a *rotating-axis tensor sheet* and the surface-wave E (along rho-hat) is *reflected about the slot axis a*: current direction chi = 2a - phi_ray, i.e. the component along the slot axis keeps its sign, the component across the slot is reversed, equal magnitudes. The static table (`SupercellTable`, MoM rows `rows_RT5880.jsonl` / `supercell_table_*.json`) is labelled GAMMA_0_COLLINEAR_ONLY: alpha_leak and beta are for the ray ALONG the slot axis (collinear); the across response is not in the table but assumed to be -(along). Which axis carries the "+" is a convention: swapping them (axis + 90 deg) multiplies EVERY static current by -1, a global sign that no static-only board can show, so the HFSS-validated hex150 board (identity, corr 0.994) validates the reflection law but not the +/- assignment of the axes.
- **Board beta / alpha:** `sub6_final_cal.py:3,8,82`: along the slot = x of the MoM, across = y; beta(theta') = beta_along cos^2 + beta_across sin^2 with theta' = ray angle - slot axis. The HFSS island-cell points (`results/sub6_final_board/hfss_data.json`) carry the user's own "along" / "across" labels (user note 2026-11-09: frame across = $ph_x, along = $ph_y; the 2026-11-08 package text says ALONG = $ph_x), so the $ph_x swap is absorbed by the labels, not by code.
- **Island (switched) cell:** the island rows have complex Delta (mS) from the MoM (OFF_BAR50 / ON_BAR50), A_perp = 0 (x-mirror symmetric). The model's ON/OFF sign is **`sub6_board_model4.py:62`: `sgn = +1 if Im(Delta_ON)/Im(Delta_OFF) > 0 else -1`, `:67 ratio = sgn*sqrt(alpha_ON/alpha_OFF)`, used in `:241 sgn_on` and `:275 sgn = (1-2 flip)*sgn_on`** (header comment: "the sign from the reactance polarity: my modelling choice"). The one selected row (ISL_W2.9_q0.8_Li0.5_c0.6) has Im Delta_OFF = -6.365 mS, Im Delta_ON = +14.468 mS, so the sign is -1 for all 240 cells (`rho_d` = -0.323). Delta comes from the MoM, not from HFSS: the HFSS calibration (`sub6_final_cal.py`) calibrated only beta (and alpha_x), "|Delta| does not enter the board metrics". This sign (and the physical meaning of "the current of a cell relative to the mean sheet") is the one unverified convention that the HFSS board result contradicts.
