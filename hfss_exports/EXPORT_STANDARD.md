# HFSS export standard for periodic unit-cell / eigenmode packages (2026-11-05)
Established after the RT5880 coded-cell validation (HFSS 10.670 / 11.006 GHz, cell switches). Two setup errors had produced "no switching" results.
1. **Material.** A STEP file carries no material: every object imports as vacuum. Step 1 of every setup sheet, in bold: *assign material `pec` to the metal object(s) (and the ground)*. Export all metal (patch, ground) as ONE object `METAL_PEC`.
2. **Air box = ground bottom to lid, single face per side wall.** `AIR` is one vacuum box from the bottom of the ground to the PEC lid; it overlaps the substrate and metal on purpose (nothing subtracted, so every side wall is one face). Periodic (lattice) pairs go on the four side faces of `AIR` only. Pairs on the air faces above the substrate alone leave the substrate side walls PEC (unassigned faces default to PEC) and give a bare-substrate answer.
3. **Names and sheets.** Objects `METAL_PEC`, `SUBSTRATE`, `AIR`, and lumped sheets `DX_SHEET`, `DY_SHEET` (zero-thickness, in the patch mid-plane, edges on the metal edges they bridge, >= 0.1 mm clearance from each other and from other metal). One geometry file + a state table (`states.csv`): states differ only in RLC values.
4. **Checks before export and on the re-imported STEP** (`scripts/research/check_step_cell.py`): bodies/names, no intersecting solids (metal, substrate), air box ground-to-lid with 6 faces containing all solids, geometry vs the MoM mask, rims/features present at all ends, symmetry, sheet edge coincidence, sheet clearances, EXACT_DIMS (0.001 mm snap, 0 inexact literals).
5. **Sheet content:** pec step first; air box and side-face pairs with `$ph_x` / `$ph_y`; substrate material; PEC lid on the top face of `AIR`; RLC per state with explicit current-line coordinates; Clean Up Solutions before each run; a sanity number (bare substrate, then the OFF state clearly different); predictions per run; <= 1 page.
Reference implementation: `scripts/research/sidequest_rt5880_cell_package.py` (`hfss_exports/sidequest_rt5880_cell/`).
