Board

Design method

Advanced

Accurate uses a finer mesh for the board's own unit-cell data (slower, less staircasing error); not a substitute for HFSS validation.

Set automatically from the unit-cell data (centre of the usable range, largest symmetric depth) once it's ready; edit here to override.

Multiplexing

Full aperture: every beam's hologram is superposed everywhere (the default). Sectors: each beam owns its own wedge of the board (nearest to its own φ) — typically higher gain per beam, fewer simultaneous beams per cell.

Feeds

Feedx (mm)y (mm)AmplitudePhase (°)Source

Superposition sums every feed's field (paper eq. 5) — simple, but typically costs some aperture efficiency vs. a single feed. Segmentation gives each feed its own region of the board instead. Assign each beam to a feed with the "Feed" column in the beam table above (added automatically once 2+ feeds exist).

A feed with no uploaded file uses an analytic surface-wave model (needs the board's own εr/thickness, already set above).
