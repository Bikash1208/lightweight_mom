# Neighbour-coupling (local-periodicity) check of the 1-bit cell pairs — Phase 25

**Status: awaiting HFSS** (model-only MoM reference). Question it answers: is a cell's reflection, next to cells of
the other state, what the isolated-cell model says? The Phase 21–23 boards assume it is. The MoM (periodic
supercells, plane wave) says it is not at the 0.55 mm-gap pair — see `results/phase25/README.md`. Units: mm.

Generated by `scripts/research/phase25_locality_package.py` (STEP + `mom_reference.csv`, only `*.step` are
regenerable) and `scripts/research/phase25_locality_blocks.py` (blocks + `mom_order_power_fractions.csv`).

## Stack (every STEP)

Zero-thickness sheets, the solver's own model (`src/export/array_export.write_hfss_step`): `Substrate` box
z ∈ [−1.575, 0] — Rogers RT/Duroid 5880, εr = 2.2, tanδ = 0.0009; `Patches` — assign **Perfect E**; `Ground`
at z = −1.575 — **Perfect E**. Empty cells simply have no patch. Add an air box above (≥ 15 mm), **master/slave
(linked) boundaries on the four side walls** and a **Floquet port** on top, de-embedded to a reference plane (below).
Normal incidence, x-polarised; frequencies 10.33 / 10.54 / 10.75 GHz; adapt at 10.75 GHz, ΔS ≤ 0.005. Time
convention exp(+jωt) as in the solver. Put the 5×5 / 4×4 blocks in a periodic box too (they are periodic blocks:
the MoM solved them as supercells).

## MoM reference

`mom_reference.csv`: per pair and frequency, the isolated square and empty cell, and the (0,0)-order S11_xx of
the 1×2 and 2×2 supercells, at the patch plane (`ref0mm`) and 5 mm above it (`ref5mm`, as the libraries store it),
plus the isolated-cell model's value for the same quantity. Solver: grounded periodic MoM, mesh-aligned squares
(`mom_square_side_mm` is the side the mesh represents: 5.867 / 5.333 / 6.857 mm), harmonic cut-off matched between
the isolated and supercell solves; the 1×2 is solved as a 2×2 with identical rows.

At 10.54 GHz, patch plane (HFSS is expected to give |S11| ≈ 1 for these sub-λ cells — energy conservation — so
**the phase is the observable**):

| pair | 1×2 MoM | 2×2 MoM | isolated-cell model (|Γ|, phase) |
|---|---|---|---|
| current 5.85 | 0.999 ∠ 106.3° | 0.999 ∠ 99.2° | 0.011 ∠ 58.7° (cancels: not a prediction) |
| separation-best 6.85 | 0.997 ∠ 83.5° | 0.998 ∠ 84.4° | 0.072 ∠ 54.0° (cancels) |
| locality-best 5.33 | 0.999 ∠ 118.2° | 0.999 ∠ 116.4° | 0.814 ∠ 102.8° |

`mom_order_power_fractions.csv`: for each 5×5 / 4×4 block (pattern as a row-major 0/1 string, 1 = square) the
power fraction in each propagating Floquet order from the MoM and from the isolated-cell model (renormalised to the
MoM's radiated total, as the pattern model's own normalisation does), and the error in percentage points. These
are the large-block numbers to compare with HFSS Floquet-mode powers (include the four first-order modes).

## How to read the result

* HFSS phase of the 1×2 / 2×2 S11 close to the MoM column ⇒ the MoM coupling picture is right and the 0.55 mm-gap
  boards' cell-wise model is poorly supported; close to the isolated-model column (only meaningful for the
  locality-best pair) ⇒ the MoM exaggerates the coupling.
* Report single-cell phases too: they re-check `results/phase25/gap_pair_study.json` and the mesh sensitivity
  (isolated square MoM: −40.6° at the 5.867 mm geometry, mesh 48; Phase 22's corrected value for 5.85 mm: −41.4°).

## What to send back

One CSV per case: frequency, complex S11 for both Floquet modes (note which is x-polarised, and the de-embedding
plane); for the blocks, the power in each propagating mode. Put them in `hfss_results/` here.
