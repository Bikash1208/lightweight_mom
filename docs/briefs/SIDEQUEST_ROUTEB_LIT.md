## 2. Architecture (b) as a grounded surface-wave cell (CONCEPT; NOT validated; first-order lumped numbers only)
**Structure.** Metal layer 1: top patch (disc / square) in a square lattice. Substrate (one Rogers laminate). Layer 2 (bottom): ground plane with an anti-pad; a via runs from the patch centre down to an island inside the anti-pad; the PIN diode is soldered on the bottom side bridging island to ground. The top surface carries no bias lines, no diode, nothing but patches. **Two metal layers if the bias trace to each island stays on the bottom layer (it then cuts the ground by a slot per cell row, which leaks and breaks the ground continuity); a clean ground needs a third metal layer behind the ground (bias layer + second dielectric), as in Boyarsky #6 / Zhao #7. State honestly: 3 layers is the safe option, 2 layers only with a bias trace in a ground slot.** DC path (R3): patch + via + island = anode net, one bias line for the board (one control line); cathode = ground. Both diode terminals have a DC path; no floating patch.
**TM support.** The bare grounded slab supports the TM0 surface wave at all frequencies; a TM wave needs an inductive effective top reactance (transverse resonance Y_sheet + Y_slab + Y_air = 0). With the diode ON the patch is shorted to ground through the via: the patch array becomes a mushroom, inductive below its resonance, so the TM wave is bound and beta/k0 rises (X_s = eta sqrt((beta/k0)^2 - 1)). With the diode OFF the via is open at the back (28.16 fF = -540 ohm at 10.5 GHz) and the patch array is a plain capacitive sheet (gap capacitance), which lowers beta / pushes the wave toward the light line and radiation. So the contrast is the sign change of the sheet susceptance, not a resonance shift.
**Contrast mechanism, first order** (lumped, my estimate, to be replaced by Bloch solves): ON = via inductance (about 0.7 nH, X about +46 ohm) + 2.44 ohm in shunt with the patch capacitance (about +7 mS): inductive shunt about -21 mS, net about -14 mS; ON loss about 5 % (Q about 19); the shunt LC resonance lies near 18.5 GHz (0.57 f0 at 10.5 GHz: not a resonance, but ON is enhanced by 1/(1-f^2/f0^2) = 1.47, so the via length and diameter are tolerance-critical); OFF series resonance of via + 28.16 fF near 36 GHz. **Open items:** the diode package inductance and the island/anti-pad capacitance are NOT in the measured model (ON 2.44 ohm, OFF 28.16 fF) and must be added as geometry, not as borrowed numbers (M4). Contrast may be too large (alpha scales with delta-Y squared): a series element / thin via / partial patch tunes it down.
**Isotropy.** A centred C4v patch with a central via is isotropic for the cell; the square lattice still differs between x / y and the 45 deg path (period sqrt2 p, different phase per cell), so the 3 % check of R6 needs Bloch solves along x, y and 45 deg. Cross-pol (R7) is zero by mirror symmetry along x and y; at 45 deg it follows from the lattice and must be extracted.
**Risks.** (1) Anti-pad and via leak the TM wave to the back (radiating from the ground); (2) bias slots in the ground (2-layer variant); (3) via-inductance tolerance (drill, plating) enters beta directly; (4) alpha too large in ON.
