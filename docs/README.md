# Docs index

**New here? Read [`START_HERE.md`](START_HERE.md) first, then [`ROADMAP.md`](ROADMAP.md) and [`STATUS.md`](STATUS.md).**

| File / folder | What it is |
|---|---|
| [`START_HERE.md`](START_HERE.md) | Onboarding: purpose, design flow, repo map, conventions that bite, working method. |

| [`STATUS.md`](STATUS.md) | Single source of truth for *now*: last tag/commit, capability matrix with validation level, known limitations, open next steps, parked ideas. |

| [`USER_GUIDE.md`](USER_GUIDE.md) | Walkthrough of every app page. |
| [`DEVELOPING.md`](DEVELOPING.md) | Setup, test markers, adding a solver capability, what's excluded from git and how to regenerate it. |
| [`validation/README.md`](validation/README.md) | Every validation run (HFSS comparisons, independent cross-checks, paper reproductions), with numbers and provenance. |
| [`theory/`](theory/) | `CONVENTIONS.md` (single source of truth for signs/units), `GREEN_FUNCTION.md`, `MOM_FORMULATION.md`, `S_PARAMETERS.md`, `DATABASE.md`. |
| [`history/`](history/) | The full phase-by-phase project history (`PROJECT_HISTORY.md` plus one write-up per phase) and every completed brief (`history/briefs/`). |
| [`briefs/`](briefs/) | Active work items (see [`briefs/README.md`](briefs/README.md) for the workflow) plus `_parked/` ideas not yet underway. |
| [`references/`](references/) | Index of reference papers (citation + DOI + what each is used for); the PDFs themselves are gitignored. |
| [`screenshots/`](screenshots/) | App screenshots used by `README.md` and `USER_GUIDE.md`. |
| [`submission/`](submission/) | A frozen set of figures/exports produced for a specific submission/review (not regenerated routinely — see its own files for which script made each one). |
