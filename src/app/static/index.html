Local reflectarray / holographic metasurface antenna (HMSA) design tool. Runs entirely on this machine -- no data leaves it. Every design produced here is a lookup-table / local-periodicity design to be verified in full-wave (the standard reflectarray workflow); results are labelled accordingly, never presented as more validated than they are.

Start with Unit cell to characterize a patch geometry, or Library to build/browse a phase-vs-size sweep, then use that library in Reflectarray or HMSA designer.
